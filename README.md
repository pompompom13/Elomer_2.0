# ЭЛОМЕР

ЭЛОМЕР помогает командам планировать визиты медпредставителей. Он собирает данные по городам и учреждениям, оценивает охват, строит расписание и маршруты и выгружает результаты в Excel и PDF. Раздел «Данные» сверяет адреса заказчика и рассчитывает нумерическую дистрибуцию по данным Ютеки и реестру аптек ДСМ.

Интерфейс написан на React и TypeScript, карты работают на Leaflet. FastAPI принимает параметры и файлы, запускает расчёты и формирует отчёты. Сервер хранит рабочие данные на диске в `backend/data/`.

## Запуск на Windows

Понадобятся Python 3.12, Node.js с npm и, для работы с репозиторием, Git. Сборка на сервере и в GitHub Actions использует Node.js 20.

1. Если вы открыли свежий клон, восстановите `backend/data/` из рабочей копии ЭЛОМЕРА. Для тех же результатов нужны те же справочники, настройки и проекты. Подробнее в [разделе о данных](docs/architecture.md#рабочие-данные).
2. Откройте `run.bat` в корне проекта. При необходимости он создаст окружение Python, установит зависимости и соберёт интерфейс.
3. Откройте <http://127.0.0.1:8000/>. API описан в Swagger по адресу <http://127.0.0.1:8000/docs>.

Без рабочей папки данных можно собрать интерфейс и проверить, что сервер импортирует приложение и формирует схему API. Для планов, ранее сохранённых проектов, сверки и ND нужны соответствующие данные. При отсутствии индекса городов приложение может попытаться построить его через OpenStreetMap.

## Режим разработки

Из корня репозитория. Для первого запуска выполните команды установки зависимостей. `npm ci` устанавливает версии из `frontend/package-lock.json`.

```powershell
py -3.12 -m venv backend/.venv
.\backend\.venv\Scripts\python.exe -m pip install -r backend/requirements.txt
npm --prefix frontend ci
```

Запустите API в одном терминале и Vite в другом.

```powershell
.\backend\.venv\Scripts\python.exe -m uvicorn app.main:app --app-dir backend --host 127.0.0.1 --port 8000 --reload --reload-dir backend/app
```

```powershell
npm --prefix frontend run dev
```

Vite открывается на <http://localhost:5173/> и передаёт запросы `/api` на порт 8000. Если API уже запущен через `run.bat`, используйте этот процесс.

## Структура репозитория

| Путь | Назначение |
| --- | --- |
| `frontend/src/` | Экраны, компоненты, карты, стили и вызовы API |
| `backend/app/` | API, расчёт планов, работа со справочниками, аналитика и отчёты |
| `backend/tools/` | Скрипты проверки базы для разработчика и администратора |
| `deploy/` | Docker, Caddy и команды установки и обновления сервера |
| `docs/` | Описание модулей, данных и публикации на GitHub |
| `.github/workflows/check.yml` | Сборка интерфейса и проверка импорта API при push в `main` и при pull request |
| `examples/` | Папка для локальных примеров и отчётов |
