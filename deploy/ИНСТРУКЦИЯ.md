# ЭЛОМЕР в интернете: пошагово

Итог: ЭЛОМЕР открывается по адресу вроде `https://elomer.company.ru`. Прежде чем показать любую страницу,
браузер спрашивает логин и пароль. Без них не видно ничего — ни интерфейса, ни данных, ни выгрузок.
На сервере хранятся хэши паролей (bcrypt), соединение шифруется (HTTPS).

---

## 1. Арендовать сервер (10 минут)

Подойдёт любой российский хостинг с VPS: Timeweb Cloud, Selectel, REG.RU, Beget.

- Операционная система: **Ubuntu 24.04** (или 22.04).
- Конфигурация: **1–2 процессора, 2 ГБ памяти, 20 ГБ диска**.
- Способ входа: **пароль root** (проще) или SSH-ключ.

После создания сохраните выданный хостингом IP-адрес и данные для входа по выбранному способу.

## 2. Домен (по желанию, 10 минут)

С доменом браузер открывает сайт без предупреждений. Без домена тоже можно — по IP, но браузер
один раз попросит подтвердить вход на сайт с «собственным сертификатом».

Если домен нужен: купите его у того же хостинга (или возьмите поддомен у ИТ-отдела компании)
и добавьте запись **A**: `elomer` → IP сервера. Применяется от 15 минут до нескольких часов.

## 3. Упаковать ЭЛОМЕР на своём компьютере (1 минута)

Дождитесь окончания фоновых загрузок (справочник ЛПУ, пригороды), затем дважды щёлкните
`deploy\pack.bat`. Рядом с `run.bat` появится файл **elomer_server.tar.gz** — программа и все ваши данные
(базы городов, проекты, загрузки).
Справочники и проекты из свежего клона GitHub нужно предварительно [восстановить отдельно](../docs/architecture.md#рабочие-данные).

## 4. Отправить архив на сервер (5 минут)

Откройте PowerShell в корне проекта и выполните команду, подставив IP своего сервера.

```
scp .\elomer_server.tar.gz root@203.0.113.10:/opt/
```

На вопрос «Are you sure you want to continue connecting» ответьте `yes`, затем введите пароль root
(символы при вводе не видны — это нормально).

## 5. Установить (15 минут, почти всё само)

В том же PowerShell подключитесь к серверу:

```
ssh root@203.0.113.10
```

и выполните на сервере три команды:

```
mkdir -p /opt/elomer
tar -xzf /opt/elomer_server.tar.gz -C /opt/elomer
bash /opt/elomer/deploy/setup.sh
```

Скрипт спросит:
1. **Адрес сайта** — домен из шага 2 или пусто (тогда по IP);
2. **Логин** и **пароль** первого пользователя (пароль не короче 10 символов).

Дальше он сам: поставит Docker, соберёт программу, получит HTTPS-сертификат, закроет все порты,
кроме сайта и SSH, и настроит ежедневную копию данных (хранится 14 дней в `/root/elomer_backups`).

Откройте в браузере адрес, который скрипт напишет в конце, и войдите.

---

## Доступ для коллег

На сервере:

```
bash /opt/elomer/deploy/add_user.sh
```

Введите логин и пароль коллеги. Этой же командой меняется пароль (тот же логин, новый пароль).
Убрать доступ: удалите строку с логином из файла `/opt/elomer/deploy/users.caddy`
(`nano /opt/elomer/deploy/users.caddy`, Ctrl+K — удалить строку, Ctrl+O, Enter, Ctrl+X)
и запустите `add_user.sh`, нажав Enter на вопросе о логине.

Все пользователи видят одну общую базу и общие проекты.

## Обновить программу

Когда в ЭЛОМЕРе что-то поменяется: на своём компьютере снова `deploy\pack.bat`, отправьте архив (шаг 4)
и на сервере выполните:

```
bash /opt/elomer/deploy/update.sh
```

Обновляется только программа. Данные на сервере (проекты, правки, загрузки, сделанные уже на сервере)
не затираются.

## Если что-то не так

- Посмотреть, что пишет программа: `cd /opt/elomer/deploy && docker compose logs --tail 100 app`
- Перезапустить: `cd /opt/elomer/deploy && docker compose restart`
- Сайт по домену не открывается сразу после установки — проверьте, что запись A указывает на IP
  сервера, и подождите: сертификат выдаётся, только когда домен уже ведёт на сервер.

## Что важно про безопасность

- Пароли выдавайте каждому свои — так легко закрыть доступ одному человеку.
- Пароль root от сервера никому не пересылайте в мессенджерах; после установки его можно сменить
  командой `passwd`.
- В базе нет ФИО врачей — только учреждения и количество врачей; проекты и данные визитов видят
  только те, у кого есть логин.
